# Weekly Builds

**One project, one week.** Each week we pick one thing to build: an edtech tool, a micro-SaaS, a fintech utility, an ML model, a game, or a fix for a real-life problem like online queue booking. Seven days later it ships.

This isn't a "look how well I write code" portfolio. It shows **AI engineering**: picking problems, scoping MVPs, directing an AI collaborator, checking what it produces, and learning the parts that matter along the way. Every project says plainly who did what.

## How it works

- **Monday:** pick one project from the [backlog](BACKLOG.md), choose a mode, write a one-page brief.
- **Tue – Sat:** build, keeping a short daily log in the project's `JOURNAL.md`.
- **Sunday:** ship it (a live link or a one-command run), write the retro, update the table above.

The full rules are in [PLAYBOOK.md](PLAYBOOK.md).
